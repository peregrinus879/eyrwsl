- `rsw` monitors during transfers and retries transfer failures, but checks reconciliation and monitor failure only between transfers. Inspect logs before restarting; logs/readiness do not prove endpoint synchronization. `lsw`/`dsw` manage only watchers started by this implementation, not older processes. Production rsync endpoints and real WSL inotify behavior remain unverified; revisit on host validation or monitor/rsync changes. No `--delete` semantics are implemented.
- Clipboard fixtures mock Neovim and UTF-8 Windows pipes, not Windows PowerShell. Revalidate on PowerShell, WSL interop, or Neovim provider changes.
